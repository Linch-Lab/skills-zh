# 學習記錄格式

學習記錄放在 `./learning-records/`，使用連續編號：`0001-slug.md`。

它們是教學版的 ADR：捕捉非顯著課程、關鍵洞察和陳述的先前知識。

## 模板

```md
# {學到或確立的內容的簡短標題}

{1-3 句話：學到了什麼，以及為何它對未來課程重要。}
```

## 可選區段

- **Status** frontmatter（`active | superseded by LR-NNNN`）
- **Evidence**——使用者如何展示理解
- **Implications**——這為未來課程解鎖或排除了什麼

## 何時撰寫

1. 使用者展示了對非平凡事物的真正理解
2. 使用者揭露了先前知識
3. 一個誤解被修正
4. 使命因學習而轉變

不符合條件：僅覆蓋的材料、已在詞彙表中捕捉的內容、逐課活動日誌。

## 取代

當後續記錄與先前記錄矛盾時，標記舊記錄 `Status: superseded by LR-NNNN` 而非刪除。
