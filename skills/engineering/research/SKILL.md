description: 針對高信任度的主要來源調查問題，並將發現擷取為 repo 中的 Markdown 檔案。當使用者想研究某個主題、收集文件或 API 事實、或將閱讀工作委派給背景 agent 時使用。
---

啟動一個背景 agent 進行研究，讓你在它閱讀時繼續工作。

其工作：

1. 針對主要來源調查問題——官方文件、原始碼、規格、第一方 API——而非它們的二手文章。將每個主張追溯到擁有它的來源。
2. 將發現寫入單一 Markdown 檔案，引用每個主張的來源。
3. 儲存在 repo 已有此類筆記的位置；符合現有慣例，若無則放在合理位置並說明放在哪裡。
