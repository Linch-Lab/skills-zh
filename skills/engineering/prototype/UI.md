# UI 原型

在單一路由上產生幾個截然不同的 UI 變體，可從浮動底部欄切換。

若問題是關於邏輯/狀態而非外觀——錯誤分支。使用 LOGIC.md。

## 兩種子形狀——強烈偏好子形狀 A

### 子形狀 A——對現有頁面的調整（偏好）

變體在相同路由上渲染，由 `?variant=` URL 參數控制。

### 子形狀 B——新頁面（最後手段）

僅在被原型化的東西真的沒有現有頁面可嵌入時使用。

## 流程

1. 陳述問題並選擇 N。預設 3 個變體，最多 5 個。
2. 產生截然不同的變體。必須結構上不同。
3. 連接它們。建立單一切換器元件。
4. 建立浮動切換器。底部中央固定定位，左右箭頭循環。
5. 交給使用者。
6. 擷取答案並清理。

## 反模式

- 僅在顏色或文案上不同的變體、變體間共享過多程式碼、將變體接到真實變更、直接將原型提升到生產環境。
