# 原型

原型是回答一個問題的拋棄式程式碼。問題決定形狀。

## 選擇分支

識別正在回答哪個問題：

- 「這個邏輯 / 狀態模型感覺對嗎？」→ LOGIC.md。建立一個小型互動終端應用程式。
- 「這應該長什麼樣子？」→ UI.md。在單一路由上產生幾個截然不同的 UI 變體。

## 兩個分支都適用的規則

1. 從第一天就是拋棄式，並清楚標記。
2. 一個指令執行。
3. 預設無持久化。狀態存在記憶體中。
4. 跳過打磨。沒有測試、沒有超出可運行範圍的錯誤處理、沒有抽象。
5. 浮現狀態。每次動作後列印或渲染完整相關狀態。
6. 完成後擷取。將驗證過的決策折入真實程式碼。
