# 分類標籤

Skills 以五種標準分類角色進行溝通。此檔案將這些角色對應到本 repo 議題追蹤系統中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們追蹤系統中的標籤 | 含義 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需評估此 issue |
| `needs-info`               | `needs-info`         | 等待回報者提供更多資訊 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整規格化，可供 AFK agent 執行 |
| `ready-for-human`          | `ready-for-human`    | 需要人工實作 |
| `wontfix`                  | `wontfix`            | 不予處理 |

當 skill 提及某個角色（例如「套用 AFK-ready 分類標籤」），使用此表格中對應的標籤字串。

編輯右側欄位以符合你實際使用的用語。
